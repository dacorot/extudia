# Extudia - Gestor de Tareas

Un gestor de tareas CLI desarrollado en Python con persistencia de datos en JSON.

## Características

✅ Crear tareas con título, descripción y prioridad  
✅ Listar tareas con estado (completada/pendiente)  
✅ Completar tareas  
✅ Persistencia automática en JSON  

## Tecnologías

- Python 3.x
- JSON
- OOP (Programación Orientada a Objetos)

## Cómo usar
